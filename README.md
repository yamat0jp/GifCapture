# GifCapture

スクリーンショットをGif画像に納めます。試験的に作っていてジョークソフトレベルです。

ImageMagickをインストールしていれば最適化してくれるのでscoop install imagemagick

してみてはどうでしょうか。



[インストール・アンインストール]

解凍してできたファイルを保存場所に移してください。実行ファイルをクリックすれば

ソフトウェアが起動します。アンインストールはそれらファイルを削除で完了です。



PictureフォルダScreenShots GifShot にgifファイルが作成されます。
